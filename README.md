# Tic Tac Toe Game 🎮

A simple two-player Tic Tac Toe game developed using C++.

## 📌 About The Project

Tic Tac Toe is a console-based game for two players.

Players take turns placing their marks (X and O) on a 3×3 board. The first player to get three marks in a row, column, or diagonal wins the game.

## ✨ Features

- Two-player gameplay.
- Custom player names.
- Interactive 3×3 game board.
- Turn-based gameplay.
- Input validation.
- Win detection.
- Draw detection.
- Automatic display of the winner.

## 🛠️ Technologies & Concepts

- C++
- Functions
- Arrays
- Strings
- Loops
- Conditional Statements
- Structuring code using separate functions

## 🚀 How To Run

1. Download the repository.
2. Open the `.cpp` file using Code::Blocks or another C++ IDE.
3. Compile and run the program.
4. Enter the names of both players.
5. Start playing by selecting a number from 1 to 9.

**Note:** The program uses `system("cls")` to clear the console, so it is designed for Windows.

## 🎮 How To Play

- Player 1 uses X.
- Player 2 uses O.
- Select a number corresponding to an empty cell.
- The first player to complete a row, column, or diagonal wins.
